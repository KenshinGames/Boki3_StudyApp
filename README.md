# 簿記3級 合格ドリル

日商簿記3級の学習用Webアプリです。仕訳を中心に、4択・○×の練習問題120問(6分野×20問)を収録しています。

公開ページ: https://kenshingames.github.io/Boki3_StudyApp/

## 特長

- 今日の10問:間違い直しと間隔をあけた復習(1→3→7→14→30日)を優先して出題
- 分野別ドリル、間違えた問題だけの復習、⭐マーク
- 模擬試験(30問)と本番形式の模擬試験(60問・制限時間60分)、合格ラインは正答率70%
- 試験日カウントダウンと、残り日数から計算する1日のペース表示
- 正解・不正解の効果音、ダークモード、文字の大きさ変更
- 学習記録は端末内(localStorage)に保存。コードで別端末への引き継ぎも可能

## 構成

ビルド不要の素のHTML/CSS/JavaScriptです。`index.html` を開けば動きます。

- `questions.js` … 問題データ(オリジナル問題)
- `app.js` … 画面とロジック
- `style.css` … デザイン
- `sw.js` … オフライン対応(Service Worker)

問題・解説はオリジナルです。出題範囲や制度は変わることがあるため、受検前に日本商工会議所の公式情報と最新テキストで確認してください。
